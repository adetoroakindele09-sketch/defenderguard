ABOUT THE PROJECT

Malware Detection Using File Activity Analysis

Traditional antivirus software mainly depends on malware signatures. Unfortunately, newly developed malware, polymorphic malware, and zero-day attacks can evade signature-based detection.

This project introduces an intelligent behavioral monitoring system that observes how files are accessed, modified, deleted, renamed, and created. Rather than searching for known malware signatures, the system studies the behavior of running processes and predicts whether they are malicious using machine learning techniques.

By analysing file activity logs, the system can identify suspicious patterns that often indicate ransomware attacks, trojan execution, spyware installation, or unauthorized file manipulation.
