DAVE DefenderGuard - Integrated Local Monitoring Agent Setup

1. Start the Flask backend from "Project backend":
   python app.py
   Expected: http://127.0.0.1:5000

2. Serve the frontend from "Project" (for example with VS Code Live Server or):
   python -m http.server 5500

3. Open the dashboard or File Activity page and log in.

4. Click "Start Monitoring" on File Activity. The website pairs the PC and starts the Monitoring Agent ZIP download.

5. Extract DAVE-Monitor-Agent.zip and run run_agent.bat (or run: python agent.py).

6. The agent watches all accessible Windows drive roots using Watchdog filesystem events. It does not copy or archive file contents. It uses a bounded in-memory queue and debounces bursts of modification events.

7. The File Activity page polls /api/agent/status and displays the most recent agent events.

Local agent configuration uses http://127.0.0.1:5000. A ZIP generated by the backend can instead embed the deployed backend URL.

Important: A normal browser cannot silently start a Windows Python process. The website can pair and download the agent; the user must run the extracted agent.
